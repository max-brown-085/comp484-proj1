# Project 1: Personal Website (HTML & CSS)

**Due Date:** TBD (Please check the official due date on Canvas)

## 🎯 Purpose

In this project, you will apply the HTML and CSS concepts learned in class to design and build a multi-page personal website from scratch.

## 📋 General Requirements

- **Topic:** Create a site about one of your interests (e.g., a favorite movie, TV show, book, musical artist, sports team, hobby, or travel destination). Be creative! If you have an unconventional idea, we can discuss it further in class. **Note: The only topic your website cannot be is a resume site, as we will be creating one in a future assignment.**
- **File Structure:** Your project must include at least:
  - **4 HTML documents** (representing 4 separate pages). **Your main homepage must be named `index.html`.**
  - **1 main CSS document** (containing the primary styling and formatting). _Note: While a main external stylesheet is required, you are permitted to use all types of CSS (external, internal `<style>`, and inline) throughout your project._
  - Additional directories/files for your media (images, icons, etc.).
- **Technical Constraints:**
  - **No external libraries or frameworks** (e.g., Bootstrap, Tailwind) are allowed.
  - **No automated CSS code-generation**. You must come up with the structure of your site and write the HTML and CSS manually to fit your design.
  - Review lecture slides and past homework for sample code, but make sure to make the code your own. All elements and attributes covered in class are available for you to use.

## 🔍 MDN Exploration Requirement

To encourage independent learning, you must research and implement HTML/CSS features not covered in our lectures:

1. Review the [MDN Web Docs](https://developer.mozilla.org/).
2. Choose **3 HTML elements** and **3 HTML attributes** that we have _not_ discussed in class.
3. Find a practical use for them in your website.
4. **Code Comments:** Add clear comments in your HTML/CSS directly describing:
   - What they are.
   - Where they are located.
   - How you are using them.
5. **Canvas Claiming (First-Come, First-Served):** A sign-up page link will be available on Canvas for you to claim your 3 unique elements and 3 unique attributes. **No duplicates are allowed on the list between students**, so sign up early!

## ✅ Grading Criteria

Your project will be evaluated based on the following:

- **Submission:** Submit your GitHub repository link on Canvas.
- **Functionality:** The webpage renders properly in Google Chrome on a standard desktop display (Mobile responsiveness is not required for this assignment).
- **Code Quality:** HTML and CSS have proper formatting and comments where appropriate.
- **Design:** The webpage contains all required content, and is visually organized and styled according to best practices.
- **Compliance:** CSS rules and HTML tags/attributes abide by the specifications given in lectures.
- **Exploration:** Proper implementation and commenting of the unique MDN elements and attributes.

## ⚠️ Academic Integrity

This is an **individual project**.

- **Allowed:** You can discuss this project with other students. You can explain what needs to be done and give suggestions on how to do it.
- **Prohibited:** You cannot share source code.

_Note: If two submitted projects show significant similarity in their source code, **both students will receive an F** for the project. Note that a person who gives his code to another student also fails the project (you are facilitating the dishonest actions of another)._
